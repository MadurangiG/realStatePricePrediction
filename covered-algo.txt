## Practical Sessions

Linear Regression & SGD Regression (LinearRegression, SGDRegressor) — for continuous value prediction and gradient descent optimization

Logistic Regression (LogisticRegression) — for binary and multi-class probabilistic classification

Decision Tree Classifier (DecisionTreeClassifier) — for hierarchical rule-based classification and pruning

Random Forest Classifier (RandomForestClassifier) — an ensemble method combining multiple decision trees

Support Vector Machine / SVC (SVC) — for classification using hyperplanes and kernel tricks (such as RBF and Linear kernels)

XGBoost Classifier (XGBClassifier) — a gradient-boosted decision tree ensemble

Voting Classifier (VotingClassifier) — an ensemble wrapper combining Random Forest, Logistic Regression, SVC, Gradient Boosting, and K-Nearest Neighbors via soft voting

K-Means Clustering (KMeans) — an unsupervised partitioning algorithm grouping data by cluster centers

Hierarchical Agglomerative Clustering (AgglomerativeClustering) — an unsupervised bottom-up clustering technique

DBSCAN (DBSCAN) — a density-based spatial clustering algorithm for discovering arbitrarily shaped clusters and noise

Gaussian Mixture Models (GaussianMixture) — a probabilistic unsupervised clustering approach based on Gaussian distributions
